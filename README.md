# Purdue ACC Course Visualization Tool

CIT 312 Final Project

## What the app includes
- Six Purdue ACC majors shown as Bootstrap cards
- Course lists and job examples connected to each major through modals
- Interactive 10-question quiz that recommends a major
- Purdue-style black and gold theme
- Responsive layout using Bootstrap grid classes
- Hamburger menu with active internal links
- Custom favicon
- SCSS variables for colors and layout values
- Bootstrap carousel, cards, buttons, modals, accordion, tooltip, badge, alert, navbar, and forms

## How to run
Open `index.html` with Live Server or publish the folder to GitHub Pages.
