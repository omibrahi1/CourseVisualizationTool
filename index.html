Project Documentation Summary

This app uses a responsive navbar with hamburger menu, cards, buttons, modals, accordions, carousel, badges, tooltips, alerts, forms, and Bootstrap grid classes.

Cards use Bootstrap grid classes such as col-12, col-md-6, and col-lg-4 so they stack on phones, use two columns on tablets, and three columns on larger screens.

SCSS variables define the Purdue colors, shadows, and border radius. A custom favicon is included. Semantic tags, alt text, labels, aria attributes, and visually-hidden text are used for accessibility.

About This Project

This project presents six majors in Purdue's School of Applied and Creative Computing. Each major card includes program information, sample required courses, and career paths.

The application uses Bootstrap to make the layout responsive and interactive while using SCSS variables for the Purdue color scheme.
